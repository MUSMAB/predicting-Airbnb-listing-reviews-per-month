## machine learning project predicting monthly review frequency for New York City Airbnb listings using the AB_NYC_2019 dataset (48,895 listings).

## Dataset

This project uses the **New York City Airbnb Open Data (2019)** dataset, containing 48,895 Airbnb listings.

- Source: [Kaggle — New York City Airbnb Open Data](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)
- Original data source: [Inside Airbnb](https://insideairbnb.com/)
- License: [CC0 1.0 Universal (Public Domain)](https://creativecommons.org/publicdomain/zero/1.0/)
- File: `AB_NYC_2019.csv`

## Methods

Exploratory Data Analysis (EDA) and feature engineering

Data preprocessing and regression modelling with Scikit-learn

Cross-validation and hyperparameter tuning using GridSearchCV

Random Forest regression and SHAP model interpretation

## Results

Test R²: 0.508

Test RMSE: 1.239

Objective: Estimate monthly review frequency and identify influential listing characteristics.
